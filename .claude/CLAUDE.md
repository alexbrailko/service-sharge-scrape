# Project conventions

## Code comments

Never write comments in code. This applies to all languages and all file types in this repo.

- No explanatory comments, no section headers, no `TODO`/`NOTE`/`FIXME` markers.
- No JSDoc/TSDoc blocks.
- No commented-out code.
- Do not add a comment even to explain a non-obvious workaround. Make the code self-explanatory through naming and structure instead.

When editing a file that already contains comments, leave the existing ones alone unless the change makes them wrong. Do not add new ones.
